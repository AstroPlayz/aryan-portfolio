# Aryan Anand - Personal Portfolio

A sleek, responsive personal developer portfolio website showcasing my projects, skills, and experience. Built with HTML, CSS, and modern web design principles.

## 🚀 Features

- **Responsive Design**: Fully responsive layout that looks great on mobile, tablet, and desktop devices.
- **Modern UI/UX**: Clean aesthetic featuring a dark theme with neon accents (`#3ce8c8` and `#75bfff`).
- **Project Showcase**: Dedicated sections to highlight open-source contributions and personal projects like my Quant Research Platform and Image Morpher.
- **Performant**: Lightweight and fast-loading, built purely with semantic HTML5 and CSS3 (no heavy frameworks).

## 🛠️ Built With

- **HTML5**
- **CSS3** (Custom Properties, Flexbox, CSS Grid)
- **Google Fonts** (Space Grotesk & Sora)

## 💻 Getting Started

Since this is a static website, getting it running locally is incredibly simple:

1. Clone the repository:
   ```bash
   git clone https://github.com/AstroPlayz/aryan-portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd aryan-portfolio
   ```
3. Open `index.html` in your favorite web browser.
   *(Alternatively, use an extension like VS Code Live Server for hot-reloading during development).*
